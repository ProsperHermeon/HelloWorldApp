# HelloWorldApp

A simple Python "Hello, World!" program that introduces my learning goals for CSE 310.

## About

This project is a starter exercise for CSE 310. It prints a styled greeting along with the three core topics I plan to explore during the course.

## Learning Goals (CSE 310)

1. **JavaScript** — Master modern JavaScript fundamentals and asynchronous programming.
2. **Web Apps** — Build responsive, full-stack web applications.
3. **SQL Databases** — Design relational schemas and write efficient queries.

## Requirements

- Python 3.x

## How to Run

From the project directory, run:

```bash
python3 hello.py
```
