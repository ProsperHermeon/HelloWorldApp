

# Overview

As a software engineer beginning my journey into applied programming, I created this Hello World program to set up my development environment and practice the workflow I will use throughout the semester, including writing code, documenting it, publishing to GitHub, and recording video demonstrations.

This software is a Python program that displays a styled greeting to the terminal along with a list of my learning goals for CSE 310. It uses functions with docstrings, formatted string output, and list iteration to produce a clean, readable output.

My purpose for creating this software was to verify that my development tools are properly configured and to familiarize myself with the submission process for future modules.

[Software Demo Video](https://www.loom.com/share/9afefa8b6aa943709adb1933baf2df7b)

# Development Environment

I used Visual Studio Code as my code editor and Git for version control. The code was written and tested on macOS using the built-in terminal.

The programming language used is Python 3. No external libraries were required — only the Python standard library.
